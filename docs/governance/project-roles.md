# Project roles and public claims

LABIO.NETWORK combines academic research, software development and infrastructure
operation. Public material must distinguish these roles instead of implying that one
organization owns or guarantees every component.

## Roles to record

| Role | Responsibility |
|---|---|
| Scientific coordination | Research direction, methods and scientific validation |
| Software maintainer | Source code, releases, issue management and security updates |
| Platform operator | Production services, incident response and user support |
| Infrastructure provider | Servers, accelerators, networking and local governance |
| Funding institution | Support governed by the applicable award or agreement |

The repository currently identifies Universidade do Estado de Santa Catarina — UDESC
as the coordinating institution. Any additional role attributed to BIOCORE or another
organization should be published only after the responsible parties confirm the wording,
brand use, intellectual-property position and operational responsibility.

Hardware that is expected, requested or dependent on funding must not be described as
installed capacity. Partner names, grant identifiers and procurement details require
review against the corresponding agreement before publication.
