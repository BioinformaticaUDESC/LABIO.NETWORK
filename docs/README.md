## Maturity terminology

| Label | Meaning |
|---|---|
| Operational prototype | Running implementation under active validation |
| Closed testing | Available only to an authorized test group |
| In development | Code or integration is being actively developed |
| Planned | Approved architectural direction without a production claim |
| Proposed | Dependent on funding, acquisition or institutional approval |
| Capacity scenario | Mathematical or benchmark-based simulation; not installed inventory |

Specifications are expected to evolve following security review, scientific
validation, benchmarks and operational experience.
