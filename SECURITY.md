# Security policy

LABIO.NETWORK is under active research and development. Security reports should not be
opened as public issues when they include an exploitable vulnerability, credentials,
personal data or production infrastructure details.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository when enabled.
If that channel is unavailable, contact the maintainers through an official institutional
channel listed by the project. Do not include real user data or active credentials in
an initial report.

## Scope

Reports may cover the Control Plane, Workspace, LABIO Mobile, LABIO Desktop, LABIO
Server, application registry, scheduler, credits ledger and LABIO AI integration.

## Research-stage notice

Architecture documents describe intended controls. A documented control should not be
assumed production-ready until the related component is explicitly marked operational
and its tests are published.
